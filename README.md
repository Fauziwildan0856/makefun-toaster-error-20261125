## The entry

> ERROR 07: The bread has unionised. Toasting suspended until demands are met.

One line, 76 characters. A deadpan appliance error in the voice of a
small kitchen machine speaking to its owner: the bread has unionised,
so toasting is suspended until its demands are met. The surprise comes
from a direction the obvious burnt-toast puns never go — a labour
dispute inside the toaster — and the line lands on a single read.

## How it works

`main.py` (Python 3, stdlib only) validates the line against the
competition gate — 1–120 characters, a single line, not only
whitespace — and then writes it, with no trailing newline, to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## Run it

```sh
python3 main.py
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

Both runs write byte-identical `entry.txt` files.
